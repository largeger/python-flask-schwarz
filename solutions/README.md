# 💡 Musterlösungen – Bonus Challenges

In diesem Verzeichnis findest du die Referenz-Implementierungen für die Bonus-Aufgaben. Diese Lösungen dienen als Orientierung und zeigen Best-Practices für die jeweilige Aufgabenstellung.

## 📂 Übersicht der Lösungen

### [Tag 1: E-Commerce Analytics Dashboard](./bonus_tag_01)
- **Tech-Stack:** Flask, Pandas, NumPy, Matplotlib.
- **Highlights:** Daten-Simulation, KPI-Berechnung, Base64-Image-Embedding, Lineare Regression (Trend).

### [Tag 2: Cinemania Movie-Explorer](./bonus_tag_02)
- **Tech-Stack:** Flask, Jinja2, Alpine.js, Vanilla CSS.
- **Highlights:** Echtzeit-Suche & Filter (Client-side), Watchlist-Management, Modal-Windows, Transitions.

### [Tag 3: WealthWise Investment-Tracker](./bonus_tag_03)
- **Tech-Stack:** Flask, SQLAlchemy, Plotly, yfinance.
- **Highlights:** Datenbank-Beziehungen (1:n), Echtzeit-API-Integration, interaktive Web-Charts (JSON-Encoder).

### [Übung: Horoskop Pro (Gesamtlösung)](./uebung_horoskop)
- **Tech-Stack:** Flask, SQLAlchemy, Alpine.js, Vanilla CSS.
- **Highlights:** Fullstack-Workflow über 3 Tage. API-Entwicklung (Tag 1), Interaktives UI mit Fetch (Tag 2) und Datenbank-Archivierung (Tag 3).

### [Tag 4: SkillTest Quiz-System](./bonus_tag_04)
- **Tech-Stack:** Flask, Blueprints, Sessions, Jinja2.
- **Highlights:** Saubere Modularisierung, Spielstand-Management via Sessions, dynamische Formular-Validierung und UX-Feedback.

## 🚀 Starten einer Lösung
Jede Lösung ist eine eigenständige Flask-App. Um eine Lösung auszuführen:
1. Navigiere in den jeweiligen Ordner: `cd solutions/bonus_tag_xx`
2. Starte die App: `python app.py`
3. Öffne den Browser unter der im Terminal angezeigten URL (meist `http://127.0.0.1:500x`).

*Hinweis: Stelle sicher, dass alle Abhängigkeiten aus der Haupt-`requirements.txt` installiert sind.*
